Detailed Description

Make an object transformable with position, rotation and scale. Define a pivot point.

Default constructor.

Construct with default values.
Position = {0,0}, angle = 0, scale = {1,1}, center = {-1, -1}.
A {x < 0, y < 0} center represent default center value which is {weight/2, height/2}
